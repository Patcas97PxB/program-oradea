# Program Oradea

Aplicație web instalabilă (PWA) pentru colegii de la Oradea: intervențiile din programul zilnic (predări, preluări,
transferuri, service), cu preluare, RFR, apel client, traseu Google Maps și notificări.

Depozitul conține doar codul aplicației, fără date. Datele vin de la un script Google, doar după autentificare
cu utilizator și parolă (cont propriu pentru fiecare coleg).
