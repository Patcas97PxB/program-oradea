# Program Oradea

Aplicație web instalabilă (PWA) pentru colegi: intervențiile din programul zilnic (predări, preluări,
transferuri, service), cu preluare, RFR, apel client și traseu Google Maps.

Depozitul conține doar aplicația. Datele vin de la un script Google protejat cu cheie,
care se introduce pe fiecare telefon la prima pornire.
